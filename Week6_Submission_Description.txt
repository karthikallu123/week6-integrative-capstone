This project is completed as the Week 6 Integrative Capstone Project and Evaluation for the Virtual Data Science with Python Trainee internship. The purpose of the capstone is to combine the major data science skills developed during the internship into one coherent end-to-end workflow. The project uses the publicly available Titanic dataset that was acquired, cleaned, explored, clustered, and modeled during the earlier weekly tasks, allowing the final project to demonstrate continuity rather than treating each week as an isolated exercise.

The pipeline begins with data preparation and quality checks, followed by exploratory data analysis and visualization. Descriptive statistics are used to quantify the dataset, including the number of records, target distribution, age statistics, and fare statistics. Feature engineering adds FamilySize, IsAlone, and FarePerPerson-related information where appropriate, while identifiers are excluded from modeling because they do not represent meaningful passenger characteristics.

The capstone includes an unsupervised learning stage using K-Means clustering on standardized passenger and travel features. Candidate cluster counts are examined using silhouette scores, and a five-cluster solution is retained for continuity and interpretability. Cluster profiles are analyzed using passenger counts, age, fare, class, family-travel variables, cabin availability, and post-clustering survival rates.

The supervised learning stage implements Logistic Regression and Random Forest classifiers with stratified train-test splitting, preprocessing pipelines, and multiple evaluation metrics. Logistic Regression achieved 83.24% test accuracy and 0.872 ROC-AUC, while Random Forest achieved 80.45% test accuracy and 0.847 ROC-AUC. The capstone also incorporates the PyTorch deep learning model developed in Week 5, which achieved 84.36% test accuracy and 0.857 ROC-AUC on its held-out test set.

The final report evaluates the complete pipeline, discusses model behavior and limitations, explains challenges and successful practices, and identifies possible future improvements. Visualizations, Python code, datasets, model artifacts, and documentation are included in the GitHub repository to support reproducibility.
